# Аудит и незавершённые данные

Исходные семь файлов команды используются только для чтения. Их SHA256 записаны
в `data/benchmark/manifest.json`. Производная копия не является проверенным снимком.

## Выполненная нормализация

- Явные рублёвые суммы переведены через Decimal в целые копейки.
- Синтетические транспортные цены стали `unknown` с `amount_kopecks: null`.
  Исходные значения остаются в исходном файле, связанном с манифестом по hash.
- `not_checked` заменён на `unknown`; подтверждённой доступности не добавлено.
- Для проживания исправлена одна пропущенная запятая после названия stay_18.
  Манифест содержит точный исходный и исправленный фрагменты.
- Массив проживания получил стандартную оболочку. Непроверенные рейтинги не
  используются как признаки предпочтений; они сохранены в исходном файле.
- train_return_10 исключён из производной копии: ID станции прибытия неизвестен.
  Выдуманный ID не добавлялся.
- URL дополнительных источников с неизвестным checked_at сохраняются, но
  не подтверждают перечисленные в supports факты.

## Что необходимо получить от команды

1. Транспорт на 17–18 октября: архивное подтверждение расписания, цены за
   взрослого, обязательных сборов, доступности на момент снимка и станций.
   Текущие 20 записей не дают подтверждённых транспортных цен.
2. Проживание: выбрать небольшое подмножество из 50 объектов и подтвердить
   вместимость, состав тарифа, даты, заселение/выселение, багаж, завтрак.
   Синтетические значения из notes нельзя считать политикой отеля.
3. Места: все шесть пока являются шаблонами. Нужны названия, реальные адреса,
   стоимость, часы, длительность, условия бронирования и источники.
4. Питание: время проверки источников; состав полной оценки расходов;
   заведения food_04/food_05 отсутствуют, хотя на них ссылаются перемещения.
5. Перемещения: заполнить transfer_03, сверить реальные точки, добавить связи
   для альтернативных вариантов. Для общественного транспорта нужна пешая часть;
   для цены за машину — вместимость.
6. Подтверждённые признаки culture/food/comfort в диапазоне 0–100 и их
   происхождение; сохранённые источники отзывов без выдуманных цитат.
7. Полный ручной маршрут на 17–18 октября и независимый расчёт. Бюджет группы:
   ceil(стоимость × 1.2 / 10000) × 10000 копеек.

В исходном сценарии по-прежнему 24–25 октября. Новый исторический сценарий
находится отдельно в `data/benchmark/scenarios/dev/dev_01.json`; его бюджет
оставлен null. В исходном ручном плане 26 событий без времени и ссылка
train_back_01, отсутствующая в текущем транспортном каталоге.

Четыре dev- и двенадцать test-файлов пока имеют статус pending_verification.
Это спецификации случаев, а не заявления об их разрешимости. Контрольные планы
и сертификаты конфликтов не созданы, потому что подтверждённых фактов нет.
Реальные эксперименты блокируются проверкой готовности.
